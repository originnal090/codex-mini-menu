# 2.16.0：锥形描边与高刷新率移动

移动交互以 90 次／秒以上的更新频率为开发和发布目标。规则保存在根目录 `AGENTS.md`，随源码与发布包分发。性能检查覆盖所有光效开启时的右键倾斜和位置拖动。

静态内容持续使用位图缓存；时长编辑器打开时独立处理缓存，关闭后恢复。圆环停靠在卡片上时共用其下方毛玻璃材质，投影和回正保持一致。菜单收起后，圆环恢复独立的玻璃表面。

外描边按中心角度生成冷暖锥形颜色场，12 秒旋转一周。固定圆角边框采样旋转的颜色场，保证轮廓稳定。底部弥散光采用 3.6 秒完整呼吸周期，亮度、大小和位移共同变化。隐藏和关闭动画选项时停止运动。

## 性能验证

本机显示模式：2560 × 1600、240 Hz、150% 缩放，WPF 渲染层级 2。每种交互连续运行 7 秒，首秒预热，按唯一渲染时间戳计数；位置拖动仅计入窗口坐标实际变化的帧。光效全部开启。

| 交互 | 2.15.0 更新／秒 | 2.16.0 更新／秒 | 2.16.0 中位间隔 | 2.16.0 P95 |
| --- | ---: | ---: | ---: | ---: |
| 位置拖动 | 37.1 | 117.0 | 8.34 ms | 9.34 ms |
| 右键倾斜 | 92.4 | 105.9 | 9.15 ms | 11.62 ms |

这里测量 WPF 渲染更新与原生位置变化，未使用 GPU 呈现追踪来独立测量显示帧率。不同设备应重新执行基准；低刷新率屏幕应同时记录其刷新率。

`test-conic-glass.ps1` 验证圆环区域的玻璃连续性、独立圆环恢复、沿同一射线的颜色一致性、不同角度的颜色差异、呼吸亮度变化及静止模式。完整回归还覆盖屏幕边缘、窗口跟随、快速收起、计时状态和中英文主题布局。

最终完整回归通过 4627 项检查，包括 18 项锥形渐变／玻璃材质检查、27 项真实桌面窗口跟随检查。四个屏幕边缘通过扩展同一玻璃背景与原生区域，保持圆环下方材质完整。两个移动基准均通过 90+ 性能门槛。
