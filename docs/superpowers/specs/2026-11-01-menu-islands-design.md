# 小菜单悬浮岛设计

用户已确认交互预览，并要求应用到整个插件。打开的小菜单是一张完整圆角玻璃卡片，卡片内部按功能组合为悬浮岛。

沿用 WPF/.NET Framework 4.8。统一圆角、柔和阴影、细边缘和留白，继续跟随 Codex 明暗主题及自定义配色。预览确认值：岛圆角 24 DIP、岛间距 14 DIP、阴影柔化 12 DIP。外卡片圆角 34 DIP；原生窗口宽度 368 DIP（包含现有透明边缘），保持返回与入口的定位关系。

首页功能入口、设置入口各为一个岛；计时页包含导航岛、计时主岛、工作/休息时长岛、循环岛与操作区；统计页包含两个汇总岛、滑轨岛和图表岛；语言、外观、声音设置、时长滚轮浮层使用相同材料。

保持现有计时、保存、历史、音频、拖动、展开收起和键盘行为。使用真实 WPF 控件，不引入 WebView 或外部依赖。统计和计时页保持等高。验证中英文、明暗、自定义色、0–90% 透明度、长时长、运行/暂停、时长编辑、历史图和返回定位。

实现选择：共用 Theme 材料与容器，统一各页结构；按页单独复制样式会增加后续维护负担。此选择由实现者作出。用户批准的是上述卡片内岛屿布局。
