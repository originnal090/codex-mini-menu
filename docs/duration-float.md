# Duration floating panel

The work and rest duration islands each expand into a floating glass editor from their own screen position. Opening takes 190 ms with an ease-out curve. A cached 14 DIP blurred backdrop fades in as the sharp page fades out; the editor shell and controls fade in together. The transformed editor is cached for the transition and returns to live rendering when settled. Dismissal returns to the source island over 260 ms and removes the blur. The unit-label row is omitted; wheel automation names still identify hours, minutes and seconds.

The editor uses a shared easing duration for its composition properties; dismissal samples their current values so an interrupted opening remains continuous. The background cannot receive pointer or keyboard navigation while editing. Apply saves once; cancel leaves both durations unchanged. Escape, the close button and the surrounding shade dismiss the editor. Page navigation, hiding and unloading clear all temporary effects and cached images. Theme changes refresh the cached backdrop. Disabled system or menu animations use the final state immediately.

Implementation starts from the 2.14.1 source snapshot. Timer scheduling, statistics and the work/rest data model retain their existing behavior. Build and test through `dev.ps1`; run `source/scripts/test-duration-float.ps1` for animation and lifecycle regression checks and captured examples.
